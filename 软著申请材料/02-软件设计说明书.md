## 1. 引言

### 1.1 编写目的
本说明书详细描述了晨佑前端生成平台的设计思路、技术架构和实现方案，为软件著作权申请提供技术文档支持。

### 1.2 项目背景
随着软件开发行业的快速发展，开发者面临着重复编写相似代码的需求。本软件通过AI技术，根据用户描述自动生成高质量代码，大幅提升开发效率。

### 1.3 定义与缩略语
- **API**: Application Programming Interface，应用程序接口
- **JWT**: JSON Web Token，JSON网络令牌
- **OAuth**: Open Authorization，开放授权
- **SSR**: Server-Side Rendering，服务端渲染
- **FIFO**: First In First Out，先进先出

## 3. 系统架构设计

```
┌─────────────────────────────────────────────────────┐

│  └──────────┘  └──────────┘  └──────────┘          │
└─────────────────────────────────────────────────────┘
                        ↕ HTTPS
┌─────────────────────────────────────────────────────┐
│              前端应用层 (Next.js)                    │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐          │
│  │ UI组件   │  │ 状态管理 │  │ 路由管理 │          │
│  └──────────┘  └──────────┘  └──────────┘          │
└─────────────────────────────────────────────────────┘
                        ↕ API调用
┌─────────────────────────────────────────────────────┐
│              后端服务层 (API Routes)                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐          │

│  └──────────┘  └──────────┘  └──────────┘          │
└─────────────────────────────────────────────────────┘
                        ↕ 数据访问
┌─────────────────────────────────────────────────────┐
│           数据存储层 (Tencent CloudBase)            │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐          │
│  │  用户DB  │  │ 订阅DB   │  │ 支付DB   │          │

└─────────────────────────────────────────────────────┘
                        ↕
┌─────────────────────────────────────────────────────┐

│  │ 微信支付 │  │ 支付宝   │  │ GitHub   │          │
```

### 4.3 加油包模块

**功能描述**：
提供灵活的次卡购买系统，用户可按需购买代码生成次数。

**加油包套餐**：
| 套餐 | 价格 | 次数 | 有效期 | 特点 |
|-----|-----|------|-------|------|
| 基础包 | ¥9.9 | 100次 | 30天 | 即买即用 |
| 标准包 | ¥24.9 | 300次 | 30天 | 省17% |
| 高级包 | ¥79.9 | 1000次 | 60天 | 省20% |

**使用优先级**：
采用 **FIFO（先进先出）** 算法：
1. 最先购买的加油包优先使用
2. 同一加油包按购买顺序依次扣除
3. 加油包优先于订阅配额使用
4. 过期加油包自动失效

**数据结构**：
```typescript
interface UserCreditPackage {
  id: string;
  user_id: string;
  package_id: string;
  package_type: 'basic' | 'standard' | 'premium';
  credits_total: number;
  credits_remaining: number;
  status: 'active' | 'expired' | 'used_up';
  purchase_date: string;
  expiry_date: string;
  created_at: string;
  updated_at: string;
}
```

**核心文件**：
- `lib/payment/payment-config-cn.ts` - 加油包配置
- `app/api/payment/cn/credit-package/create/route.ts` - 购买API
- `lib/subscription/usage-tracker.ts` - 使用量追踪

### 4.4 支付系统模块

**功能描述**：
集成微信支付和支付宝，处理支付订单、回调通知。

**支付流程**：

```
用户发起购买
   ↓
创建订单（防重复检查）
   ↓
调用支付接口（微信/支付宝）
   ↓
生成支付二维码/跳转支付页
   ↓
用户完成支付
   ↓
接收支付回调
   ↓

   ↓
```

**防重复支付机制**：
- 1分钟内相同金额的订单视为重复

**核心文件**：
- `lib/payment/adapter-cn.ts` - 支付适配器
- `app/api/payment/cn/create/route.ts` - 订阅支付
- `app/api/payment/cn/credit-package/create/route.ts` - 加油包支付
- `app/api/payment/cn/wechat/notify/route.ts` - 微信回调
- `app/api/payment/cn/alipay/notify/route.ts` - 支付宝回调

### 4.5 使用量追踪模块

**功能描述**：
实时追踪用户的代码生成次数，超量自动限制。

**统计维度**：
- 月度周期统计（订阅用户）
- 自然日统计（加油包）
- 总量统计（企业版无限）

**限制机制**：
1. 实时检查剩余次数
2. 次数用完禁用生成按钮
3. 颜色预警（蓝→橙→红）
4. 弹窗提示升级

**核心算法**：
```typescript
// 获取用户使用统计
async function getUserUsageStats(userId: string) {
  // 1. 获取用户订阅等级
  const plan = await getUserPlan(userId);

  // 2. 统计本月使用次数
  const currentUsage = await countMonthlyUsage(userId);

  // 3. 查询活跃的加油包
  const creditPackages = await getActiveCreditPackages(userId);

  // 4. 计算总配额
  let totalLimit = plan.monthlyLimit;
  for (const pkg of creditPackages) {
    totalLimit += pkg.credits_remaining;
  }

  // 5. 计算剩余次数
  const remaining = totalLimit - currentUsage;

  return {
    current: currentUsage,
    limit: totalLimit,
    remaining: remaining,
    isUnlimited: plan.type === 'enterprise'
  };
}
```

**核心文件**：
- `lib/subscription/usage-tracker.ts` - 核心追踪逻辑
- `app/api/subscription/check-usage/route.ts` - 使用量查询API
