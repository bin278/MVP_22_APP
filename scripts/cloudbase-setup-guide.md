-- CloudBase 数据库集合创建指南
--
-- 由于 CloudBase 使用的是 NoSQL 文档数据库，不需要预先创建表结构
-- 但需要确保以下两个集合存在并设置正确的权限
--
-- 📋 需要创建的集合:
-- 1. conversations - 对话记录
-- 2. conversation_files - 生成的文件
--
-- 🔧 操作步骤:
--
-- 1. 登录腾讯云 CloudBase 控制台
--    访问: https://console.cloud.tencent.com/tcb
--
-- 2. 选择你的环境
--    环境ID: cloud1-3gn61ziydcfe6a57
--
-- 3. 点击左侧菜单 "数据库"
--
-- 4. 点击 "添加集合"
--
-- 5. 创建第一个集合:
--    集合名称: conversations
--    权限设置:
--      - 所有用户可读: false (仅创建者可读)
--      - 所有用户可写: false (仅创建者可写)
--    点击"确定"
--
-- 6. 创建第二个集合:
--    集合名称: conversation_files
--    权限设置:
--      - 所有用户可读: false (仅创建者可读)
--      - 所有用户可写: false (仅创建者可写)
--    点击"确定"
--
-- ✅ 完成后集合会自动创建，代码生成的数据就会保存到数据库
--
-- 📊 数据结构参考:
--
-- conversations 集合文档结构:
-- {
--   "_id": "自动生成的ID",
--   "user_id": "用户ID",
--   "title": "对话标题",
--   "type": "generation",
--   "prompt": "用户输入的提示词",
--   "created_at": "2025-01-08T12:00:00.000Z",
--   "updated_at": "2025-01-08T12:00:00.000Z"
-- }
--
-- conversation_files 集合文档结构:
-- {
--   "_id": "自动生成的ID",
--   "conversation_id": "关联的对话ID",
--   "file_path": "文件路径，如 src/App.tsx",
--   "file_content": "文件内容",
--   "created_at": "2025-01-08T12:00:00.000Z",
--   "updated_at": "2025-01-08T12:00:00.000Z"
-- }
--
-- 🔍 验证集合是否创建成功:
-- 1. 在数据库页面应该能看到 conversations 和 conversation_files 两个集合
-- 2. 点击集合名称，应该能看到"暂无数据"(这是正常的,第一次生成代码后就会有数据)
--
-- ⚠️ 常见问题:
--
-- 问题1: "DATABASE_COLLECTION_NOT_EXIST"
-- 解决: 集合名称拼写错误，或集合未创建
--
-- 问题2: 权限错误
-- 解决: 检查集合权限设置，确保用户有写入权限
--
-- 问题3: 环境变量配置错误
-- 解决: 检查 .env.local 中的 CloudBase 配置是否正确
